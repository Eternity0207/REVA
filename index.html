🔐 How Authentication Works

Agent Authentication Flow

  1. Agent Registration: The REVA desktop app sends its agent_id and token to the server
  2. Token Verification: Server validates the token against known agents
  3. Polling for Tasks: Agent polls for pending tasks every 5 seconds
  4. Task Execution: Agent executes commands and reports results
🔒 Security Notes:
• Tokens are validated on every request
• Only authenticated agents can fetch and execute tasks
• Results are encrypted during transmission
• Each agent maintains independent task queue
• Failed authentication returns 403 Forbidden
